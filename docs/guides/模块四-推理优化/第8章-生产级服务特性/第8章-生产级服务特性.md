## 本章简介

前七章把「装得下、跑得快、双 SLO 不互毁」的主线钉死了：分页 KV、连续批处理、量化与投机、分布式装载，以及 P/D 解耦与 Goodput（[7.4](../第7章-PD解耦架构/7.4-Goodput与SLO感知调度.md)）。产品侧下一关往往不是再抠几个百分点的 tokens/s，而是**输出形态可控、动作可解析、一份底座多业务、图文输入不打穿 Prefill**。本章不按功能清单推销特性，而是逐项问：多付多少延迟/显存，换来哪一类正确率或密度；何时该开、何时该关。

**结构化输出**把合法性前移到生成时 mask；账本在约束编译与每步合法集上，取舍是吞吐/延迟 vs 可解析率。

**Tool Calling 与 Reasoning Parser**把工具动作与思维链从自由文本里拆出来；重点是失败模式与观测点，而不是「支持哪些模型」。

**Multi-LoRA**用一份底座服务多个 Adapter；显存与切换开销可粗算，并发适配器有上限直觉。

**多模态（VLM）**用图像 Token 放大 Prefill/KV 的示意账，说明分辨率与缓存该砍哪里。

**采样与解码**把 Temperature / Top-p / `n` 等旋钮写成可检验的多样性—延迟影响，避免凭手感改参。
